# ISM Graphics Card

Expansion **graphics** board for the ISM desktop stack.

- RP2040 GPU/controller stand-in on motherboard `J_EXP` SPI/I2C
- HDMI Type-A out with on-board DDC/EDID/HPD/CEC (TMDS PHY off-board)
- Lyontek SPI PSRAM framebuffer
- Printable cooler shroud + slot bracket

Generator: `scripts/build_graphics_card.py`. Original ISM design.
