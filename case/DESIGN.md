# ISM Computer Case

SFF / mini-ITX class **chassis** with a smart RP2040 front-panel board.

- RP2040 MCU (USB-C) for power/reset buttons and status LEDs
- Dual front USB-A passthrough to motherboard USB2 header
- ATX front-panel header (PWR/RST/LED)
- OpenSCAD chassis + front bezel + top lid (STL/STEP)

Form factor: ~220×280×180 mm outer shell, front bay for 110×45 mm FP PCB.

Generator: `scripts/build_case.py`. Original ISM design.
