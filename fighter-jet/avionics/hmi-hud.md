# HUD / HMI Concept — ISM-FJ-1

## Crew interface
- **HUD** combiner at FS-28: flight path, attitude, AOA bracket, weapons cues (when MC healthy).
- **LAD** (large-area display): tactics, radar/EO, systems synoptics, ISM warm-gray industrial chrome with single accent.
- **HOTAS:** side-stick + throttle; uncage, sensors, weapons select — no mechanical flight reversion.
- **Caution/warning:** voice + lights + HUD captions; essential bus powered.

## Branding
Warp-era industrial typography; squirrel motif only as discrete status mascot / boot splash — not cluttering flight symbology. See `docs/branding.md`.

## Degraded symbology
On MC loss, FCC-driven minimal HUD set: attitude, airspeed, altitude, heading, AOA, gear.
