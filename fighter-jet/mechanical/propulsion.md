# Propulsion Concept — ISM-FJ-1

## Baseline
Twin low-bypass turbofan modules in aft fuselage (FS-82–95), side-by-side. Twin chosen for asymmetric-thrust backup and ISM multirole payload — **single-engine alternate** remains an open product decision (would shrink aft body and revise inlet).

## Interfaces
| Interface | Notes |
|-----------|-------|
| Mounts | Aft frames / thrust links into primary structure |
| Inlets | Twin side/under intakes; ducts through center-aft |
| Bleed / accessories | Generators, optional EDP if central hydro retained |
| Nozzles | Variable geometry stub; IR suppress concept only |
| Fire protection | Firewalls, bottles, detection → caution suite |

## Controls
Throttles → FCC / FADEC-class engine controllers (vendor ICD TBD). Differential thrust available as FBW secondary yaw/roll assist.
