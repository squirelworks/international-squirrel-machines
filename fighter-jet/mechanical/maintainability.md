# Access & Maintainability — ISM-FJ-1

## Design goals
- Line-replaceable units (LRUs) for avionics without fuselage splice break.
- Engine removal aft without cockpit separation.
- Wing-off transport within standard hangar doors (product width TBD).

## Access panels (concept)

| Panel | Location | Serves |
|-------|----------|--------|
| Radome hinge | FS-0–12 | Radar / EO |
| Canopy | FS-22–40 | Crew / HUD service |
| Dorsal avionics hatch | FS-48 | MC, FCC, PDU, bay PCB |
| MLG doors / wells | FS-55 | Gear, brake lines |
| Wing root upper/lower | WS-0 | Spar bolts, harness |
| TE actuator panels | WS-8 / HT / fin | EHAs |
| Engine cowl / rails | FS-82–95 | Propulsion |
| Gun / ammo door (opt.) | FS-70 | Armament |

## Captive hardware
Prefer captive fasteners on flightline panels; ISM branding-friendly warm-gray panel edges, accent only on service legends.

## Ground equipment interfaces
- Power cart / battery connect at PDU access.
- Data load panel near avionics hatch (ISM-Bus maintenance port).
- Jacking points marked at FS/WS per stations diagram.
