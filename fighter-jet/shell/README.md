# Fighter Jet Shell

Parametric OpenSCAD airframe for the ISM fighter jet.

## Files
- `airframe.scad` — fuselage, main wing, horizontal stabilizer, vertical stabilizer, avionics bay cutout, ISM badge boss

## Expected exports
- `fuselage.stl`
- `wing.stl`
- `empennage.stl` (or combined print)

Tune length / span / thickness parameters at the top of `airframe.scad` before exporting.
