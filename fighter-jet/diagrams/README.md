# Diagrams & Blueprints

Orthographic views, station diagrams, assembly breakdown, bay layouts, and harness overview for ISM-FJ-1.

| Artifact | File | Purpose |
|----------|------|---------|
| Three-view | `orthographic.svg` | Plan / side / front proportions |
| Station diagram | `stations.md` | Fuselage & wing stations (mm study / % MAC) |
| Assembly breakdown | `assembly-breakdown.md` | Major assemblies & join philosophy |
| Bay layouts | `bay-layouts.md` | Nose, cockpit, avionics, weapons, propulsion |
| Wiring / harness | `wiring-harness.md` | Power, data, actuation trunks |
| Wing plan detail | `wing-plan.svg` | Spar/rib/stations sketch |
| Systems overview | `systems-overview.svg` | Sensors → MC/FCC → EHA |
| Fuselage stations | `fuselage-stations.svg` | Side blueprint with % FS callouts |

All drawings are original ISM geometry, not traced from any real type. Dimensions in the SVG study model align with `shell/airframe.scad` defaults (~420 mm fuselage study scale). Full-scale station numbers use percentage of fuselage length (FS) so they stay valid when scale is locked.
