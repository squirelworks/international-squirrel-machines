# Structural Material Placement — ISM-FJ-1

| Location | Material (ISM designation) | Why |
|----------|---------------------------|-----|
| Outer wing skins | ISM-CFRP-A (carbon/epoxy) | Stiffness-to-weight; fatigue |
| Wing spars (caps) | ISM-Al-7 or CFRP laminate | Bending load path; hybrid baseline uses Al-7 caps + CFRP webs |
| Wing ribs | ISM-CFRP-A or Al sheet | Shape fuel cells; access holes |
| Carry-through box | ISM-Ti-6 fittings + Al-7/CFRP box | Side-of-body loads; damage tolerance |
| Fuselage longerons | ISM-Al-7 | Machinability; repairability |
| Fuselage skins (fwd) | Al skin + CFRP panels | Lightning / maintainability mix |
| Fuselage skins (aft/hot) | Ti + thermal blanket | Engine heat |
| Bulkheads (pressure) | ISM-Al-7 machined | Cockpit pressure vessel |
| Landing gear legs | ISM-Ti-6 / high-strength steel stub | Strength, corrosion |
| Control surface skins | CFRP sandwich | Light, flutter margin |
| Actuator fittings | ISM-Ti-6 | Bearing / fatigue |
| Fasteners (primary) | Ti / A286-class CRES | Galvanic compatibility with CFRP/Al |
| Radome | Quartz/epoxy (ISM-RF-Q) | RF transparency |
| Canopy | Polycarbonate / acrylic laminate | Optics + birdstrike concept |
| Avionics trays | Al honeycomb / CFRP | Stiffness, thermal path to cold plate |
| Fin / ISM badge boss | CFRP with bonded Al insert | Badge mounting without crushing laminate |

## Load-path sketch (wing)
Tip → aileron hinge → rear spar → ribs → front/rear spars → root fittings → carry-through → opposite wing / fuselage.

## Corrosion & thermal (summary)
See `metallurgy-composites.md`. CFRP–Al interfaces always isolated (glass ply / primer / sealant). Engine bay rated for continuous soak per propulsion ICD (TBD).
