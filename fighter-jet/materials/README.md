## Default materials philosophy
- **Weight-critical skins & covers:** carbon-fiber epoxy (ISM-CFRP-A)
- **Highly loaded fittings / landing gear:** titanium alloy family (ISM-Ti-6)
- **Carry-through & spar caps (baseline):** aluminum-lithium or 7xxx aluminum (ISM-Al-7) with CFRP option
- **Engine bay / hot structure:** nickel alloy / titanium; thermal barriers
- **Radome:** quartz/epoxy or similar RF-transparent composite

Product decision still open: **all-composite wing box vs hybrid Al-Li + CFRP skins**. Baseline docs assume hybrid.
