# Fab package — ISM Flash Cards reader

| File | Use |
|------|-----|
| `ism-flash-cards-gerbers.zip` | JLCPCB/PCBWay upload |
| `BOM.csv` | SMT BOM with LCSC where available |
| `ism-flash-cards-cpl.csv` | Centroid / pick-and-place |

Commodity **microSD media** is off-board. Regenerate with `python3 scripts/build_flash_cards.py`.
