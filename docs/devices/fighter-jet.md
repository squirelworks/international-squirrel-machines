# Fighter Jet

Official ISM device.

## Form factor
Single-seat fighter scale airframe with an internal avionics bay. Industrial Warp-era lines; ISM squirrel badge on the vertical stabilizer. Not a replica of any specific aircraft.

## Key components
- Flight computer MCU (RP2040-class placeholder)
- IMU (6/9-axis) for attitude sensing
- Radio / telemetry link
- Power distribution and battery connector
- Actuator channels for control surfaces (and optional propulsion ESC)
- Stick / throttle interface headers

## Mechanical
- Parametric OpenSCAD shell: fuselage, main wing, horizontal stabilizer, vertical stabilizer
- Avionics bay under canopy / dorsal hatch
- Mounting bosses for the KiCad controller board

## Branding
Warm grays / soft browns with a single accent (finalize per prototype). ISM legend on silkscreen and stabilizer badge.
