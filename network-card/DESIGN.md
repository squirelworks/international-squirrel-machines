# ISM Network Card

Expansion **network** board for the ISM desktop stack.

- RP2040 NIC/controller stand-in on motherboard `J_EXP` SPI/I2C
- WIZnet W5500 SPI Ethernet MAC+PHY (hardwired TCP/IP)
- Hanrun HR911105A RJ45 with integrated magnetics
- Printable cooler shroud + slot bracket

Generator: `scripts/build_network_card.py`. Original ISM design.
