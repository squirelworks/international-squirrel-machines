# ISM Keyboard — TKL

ANSI tenkeyless (~87 keys), 6×15 matrix (ROW0–5 × COL0–14), RP2040 module (pad 27=ROW5, pad 28=COL14), USB-C, MX hotswap, printable shell.
Original International Squirrel Machines design (not QMK).

Generate: `python3 scripts/build_keyboard_tkl.py` — **ERC 0 / DRC 0**.

VID/PID **0x1209 / 0x0004**. Issue [#64](https://github.com/squirelworks/international-squirrel-machines/issues/64).
