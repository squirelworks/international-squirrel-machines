# ISM Keyboard

First device in the International Squirrel Machines line.

## Size Variants
- `40-percent/`
- `60-percent/`
- `65-percent/`
- `75-percent/`
- `tkl/`
- `full-size/`
- `large/`
- `extra-large/`

Shared KiCad libraries and shell templates can live at the keyboard root; size-specific projects go in the subdirectories.
