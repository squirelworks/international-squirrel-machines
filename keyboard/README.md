# ISM Keyboard

First device in the International Squirrel Machines line.

## Scope
- Mechanical keyboard PCB (KiCad)
- 3D-printable shell / case (OpenSCAD)
- Hot-swap MX switches, RP2040-class MCU, USB-C
- ISM branding on the shell

## Status
Scaffolded. Ready for schematic and layout work.
