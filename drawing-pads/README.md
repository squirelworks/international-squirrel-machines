# ISM Drawing Pads

Range of digitizer / graphics tablets for the International Squirrel Machines line.

## Scope
- Multiple sizes (small, medium, large)
- Printable shells
- Controller boards (USB or serial)
- Stylus support
- ISM branding

## Status
Scaffolded. Ready for design notes and first size.
