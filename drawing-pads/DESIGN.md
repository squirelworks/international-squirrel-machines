# ISM Drawing Pads

USB digitizer pad range — **small / medium / large**.

**Default population:** XPT2046 4-wire resistive controller (LCSC **C19076**, TSSOP-16) + panel FPC `J3`.
**Optional:** `ISM:ISM_Touch4_FPC` for direct MCU ADC mode (not default SMT).

Generator: `scripts/build_drawing_pads.py`. Original ISM design.
