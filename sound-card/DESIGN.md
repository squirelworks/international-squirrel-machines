# ISM Sound Card

Expansion **sound** board for the ISM desktop stack.

- RP2040 audio/controller stand-in on motherboard `J_EXP` SPI/I2C
- TI PCM5102A stereo I2S DAC (PLL mode, SCK tied GND)
- 3.5 mm TRS line/headphone jack (CUI SJ-3523 footprint)
- Printable cooler shroud + slot bracket

Generator: `scripts/build_sound_card.py`. Original ISM design.
